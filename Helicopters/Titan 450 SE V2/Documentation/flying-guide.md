# How to fly this model

Practical order of use after the radio and mechanics are set up.

## Before every flight

1. **SF hold ON**
2. **SE = Normal**, **SC = Low rates**
3. Pack: prefer **3S** for real hovering (see [battery notes](battery-notes.md))
4. Check blades, links, tail free; gyro HH selected (**SA** positive)
5. Range / bind as you normally do for FrSky D8 (D8R-II Plus)

## Spool and hover (Normal)

1. Hold ON → radio on → model selected  
2. Hold **OFF**, collective low → spool in **Normal** only  
3. Raise collective smoothly into hover  
4. Hover should sit near **mid stick** with the Normal pitch curve (`CPI`)  
5. Use small cyclic; if it feels twitchy, stay on **SC Low** or soften rates ([dual rates](dual-rates-and-expo.md))

## Using Idle-Up

Only when already at speed and stable:

1. From a calm Normal hover or forward flight  
2. Flip **SE** to **Idle1** (then later **Idle2**)  
3. Expect steadier head speed and 0° collective near mid stick  
4. Land by returning to **Normal** when practical, or hold + careful descent per your comfort  

**Never** select Idle-Up from zero RPM with collective high.

## Rates while flying

| Situation | **SC** |
|-----------|--------|
| First hover / learning | Low |
| General upright flight | Medium |
| More cyclic authority / Idle work | High |

Rates do **not** change Normal vs Idle — that is **SE** + curves.

## After landing

1. Collective low  
2. **SF hold ON**  
3. Disarm / unplug pack
