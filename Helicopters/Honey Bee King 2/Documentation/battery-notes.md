# Battery notes

| Pack | Use |
|------|-----|
| **3S** (~11.1 V) | **Flight** — normal for HBK2 |
| **2S** | Bench / soft tune only |
| **4S** | Not for this stockish setup (ESC may allow it; airframe/motor usually shouldn’t) |

Titan-class 40A ESC on many clones: confirm BEC **5 V** is happy with your servos; don’t run a starved BEC into binding servos.
