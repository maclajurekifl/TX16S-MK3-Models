# Switch map & keybinds

![Honey Bee King 2](assets/HBK2.png)

Physical controls on the TX16S for **Esky HBK 2** (`model5.yml`).

## Switches

| Switch | Function | Positions (this backup) |
|--------|----------|-------------------------|
| **SF** | **Throttle hold** | **SF0** = override CH1 to **−100** (motor cut) |
| **SE** | **Flight mode** | Default **Normal** · **SE1** Idle1 · **SE2** Idle2 |
| **SA** | *(unused)* | No gyro gain lead on this build — leave alone |
| **SB** | **RGB lights** | Up `srain` · Mid `sapp` · Down `off` · **S1** brightness · **S2** speed |
| **SC** | **Dual rates** | **SC0** Low · **SC1** Mid · **SC2** High |
| **SD** | **Flight timer** | **SD1** start · **SD2** reset |

Confirm live labels on your radio if you remapped anything after this backup.

## Sticks (Mode 2)

| Stick | Controls |
|-------|----------|
| Collective / throttle (left) | Head speed + collective pitch (via thr/pitch curves) |
| Rudder (left yaw) | Tail (through gyro) |
| Elevator (right fore/aft) | Cyclic pitch |
| Aileron (right left/right) | Cyclic roll |

## Recommended “default” before spool

| Control | Set to |
|---------|--------|
| **SF** | Hold **ON** |
| **SE** | **Normal** |
| **SC** | **Low** rates |
| Collective | Low / idle |
| Ail / Ele trim & subtrim | **0** (fix geometry first) |
