# Swashplate levelling

Geometry reference for this flybar King 2. Do **not** use Normal pitch mid (CPI Y=40) as the level point.

## Goals

- Cyclic trim / subtrim near **0**
- At **Idle-Up mid stick**: washout/mixing arms level, swash flat, blades ~**0°**
- Servo arms as close to **90°** as splines allow (a few degrees off is OK)

## Steps

### 1. Zero the radio cyclic
Aileron/elevator trim and subtrim → 0.

### 2. Level at Idle-Up mid
1. **SE = Idle1** (or Idle2) — pitch curve mid = **0**  
2. Collective stick **centered**, cyclic centered  
3. Arms ~90° (best spline)  
4. Adjust the **three swash links** until the swash is flat  
5. Confirm washout / mixing base is level and blades read ~0°  

### 3. Check travel
Briefly check low and high collective (cyclic still centered). Mid level matters most; large twist through travel means unequal geometry.

If **low** collective packs the swash toward the frame: raise pitch-curve bottoms or reduce collective weight — **do not** move the mid/0° reference.

### 4. Directions (bench, motor unplugged)
1. Collective up → all three raise the swash (reverse the odd servo channel if one drops)  
2. Fix aileron/elevator tilt with **swash Ail/Ele weight signs**, not endless channel reverses  

### 5. Main blades
- Both grips same pitch at mid  
- Track after reassembly  
- ~278 mm stock; 300 mm OK if tip clearance is clear  

### 6. Hover check
Only **tiny** cyclic trim if needed. Still needs a lot → return to swash/arms.
