# How to fly this model

Practical order after radio + mechanics + [calibration](calibration.md) are done.

## Before every flight

1. **SF hold ON**  
2. **SE = Normal**, prefer **SC Low** while learning  
3. **SA** = **6G** for assisted hover, or **3D** if practicing without self-level  
4. Ail/ele trim & subtrim preferably **0**  
5. Level table for plug-in; wait for gyro init before moving the heli  
6. Check blades, links, main shaft, spindle/grips, skids  

## Spool and hover (Normal)

1. Hold ON → radio on → model **XK 110s** selected · bound (S-FHSS)  
2. **SF Hold OFF**, collective low → spool in **Normal** only  
3. Raise collective smoothly into a skid hover  
4. If twitchy cyclic → stay on **SC Low** ([rates](dual-rates-and-expo.md))  
5. If it walks in **6G** after a crash/rebuild → [6G hover cal](calibration.md), don’t chase with trim tabs  

## Using Idle-Up (**SE ↓**)

Only when already at speed and stable:

1. From a calm Normal hover or forward flight  
2. Flip **SE** to **Idle-Up** (`SE2`)  
3. Expect higher/steadier head speed and more pitch authority (CPI/CTI)  
4. Land by returning to **Normal** when practical, or Hold + careful descent  

**Never** select Idle-Up from zero RPM with collective high.

**Zero** (`SE` mid) is a named flight mode on this radio; thr/pitch mixes still follow Normal until Idle-Up.

## Rates while flying (**SC**)

| Situation | **SC** |
|-----------|--------|
| First hover / learning | Low (↓) |
| General upright / cal entry | High (↑ or mid) |

Rates do **not** change Normal vs Idle-Up — that is **SE** + curves.

## After landing

1. Collective low  
2. **SF hold ON**  
3. Unplug pack
