# Switch map & keybinds

![Align 450 XL](assets/Align450XL.png)

**Align 450 XL** — independent Roll / Elevate / Pitch.

## Switches

| Switch | Function |
|--------|----------|
| **SF** | Throttle hold ? Motor safe |
| **SE** | Normal / Idle1 / Idle2 |
| **SA** | Gain (CH5) |
| **SB** | Lights |
| **SC** | Rates Low / Med / High |
| **SD** | Timer |

## Sticks ? named outputs

| Stick | Output |
|-------|--------|
| Throttle / collective | **Motor** (CH1) + **Elevate** (CH3) |
| Aileron | **Roll** (CH2) |
| Elevator | **Pitch** (CH6) |
| Rudder | **Rud** (CH4) |
