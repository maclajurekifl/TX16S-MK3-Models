# Align 450 XL — setup summary

Independent servos (not eCCPM). **R86C** · FrSky X.

## Output names

| CH | Name | Function | Source |
|----|------|----------|--------|
| CH1 | **Motor** | ESC | Thr + CTH/CT1/CT2 |
| CH2 | **Roll** | Roll servo | Ail + rates |
| CH3 | **Elevate** | Collective / height | Pit + CPI/CP* |
| CH4 | **Rud** | Tail gyro | Rud |
| CH5 | **Gain** | Gyro gain | SA |
| CH6 | **Pitch** | Fore/aft servo | Ele + rates |

Swash: **TYPE_NONE**.

See [r86c-wiring.md](r86c-wiring.md) · [switch-map.md](switch-map.md).
