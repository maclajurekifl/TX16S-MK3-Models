# R86C wiring — Align 450 XL

RadioMaster **R86C** (6ch PWM). Independent servos (not CCPM).

| R86C | Name | Function |
|------|------|----------|
| CH1 | Motor | ESC |
| CH2 | Roll | Roll servo |
| CH3 | Elevate | Collective / height |
| CH4 | Rud | Tail gyro in |
| CH5 | Gain | Gyro gain (optional) |
| CH6 | Pitch | Fore/aft servo |

```
Ail → Roll (CH2)
Ele → Pitch (CH6)
Pit → Elevate (CH3)
Thr → Motor (CH1)
```
