# Align 450 XL — restore onto TX16S SD

## Drop files

1. Open: `Helicopters/Align 450 XL/SD Card Files/`
2. Copy **everything inside** to the SD root (e.g. `F:\`): `MODELS\`, `IMAGES\`, `SCRIPTS\`
3. Merge when asked (do not wipe other models’ scripts).

## Model slot

This pack uses **`MODELS/model2.yml`**.

If slot 2 is taken, rename to a free `modelN.yml` and add a labels entry (see `SD Card Files/MODELS/README-LABELS.txt`).

## Included

| Path | Why |
|------|-----|
| `MODELS/model2.yml` | Align 450 XL · CCPM · R86C RF |
| `IMAGES/Align450XL.png` | Bitmap |
| `SCRIPTS/RGBLED/*` | SB lights |

## After copy

Eject → power on → select **Align 450 XL** → bind R86C per [rf-bind-failsafe.md](rf-bind-failsafe.md).
