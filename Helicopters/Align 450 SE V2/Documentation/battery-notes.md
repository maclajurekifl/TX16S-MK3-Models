# Battery notes

## Flight pack

Use **3S (11.1 V)** for normal flying. The 450 SE is set up around that voltage for head speed and tail authority.

## 2S for tuning only

**2S is fine for setup and careful tune hops:**

- Swash level / links  
- Tracking  
- Gyro sense checks  
- Confirming cyclic trim isn’t huge after geometry work  

Do **not** treat 2S hover feel or final tail gain as gospel — re-check on **3S**.
