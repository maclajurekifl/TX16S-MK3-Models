# Switch map & keybinds

Physical controls on the TX16S for **Emax Hawk 5** (`model6.yml`). Layout mirrors the heli packs where it makes sense.

## Switches

| Switch | Function | Positions |
|--------|----------|-----------|
| **SA** | **Auto-level intensity** | 3-pos → CH8 (low / mid / high). Optional BF adjrange later |
| **SB** | **LEDs** | TX RGB: **SB0** `blue` · **SB1** `sapp` · **SB2** `off` · also CH9 AUX |
| **SC** | **Rates** | **SC0** Low · **SC1** Mid · **SC2** High (Ail/Ele/Rud expo+weight on radio) |
| **SD** | **Flight timer** | **SD1** run · **SD2** reset |
| **SE** | **Flight mode** | **SE0** Level (Angle) · **SE1** Acro · **SE2** Horizon (“3D”) |
| **SF** | **Arm / hold** | **SF0** = disarmed + thr cut (safe) · **SF1** = armed |
| **SG** | **Beeper** | **SG2** (high) = beeper AUX high |
| **SW1** | **Turtle** | On → CH10 high (spare until BF supports flip-over) |

## Sticks (Mode 2)

| Stick | Controls |
|-------|----------|
| Throttle (left) | Motor thrust (BF) |
| Yaw (left) | Yaw |
| Pitch (right fore/aft) | Pitch |
| Roll (right left/right) | Roll |

## Recommended before plug-in / arm

| Control | Set to |
|---------|--------|
| **SF** | Hold / **disarmed** (**SF0**) |
| **SE** | **Level** |
| **SC** | **Low** rates |
| Throttle | Low |
