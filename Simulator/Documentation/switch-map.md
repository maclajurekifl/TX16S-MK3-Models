# Switch map — Simulator

| Control | Function |
|---------|----------|
| **SB Up** | LEDs **off** |
| **SB Mid / Down** | **80 LED effects** (`ledfx`, Repeat ON) |
| **Btn 1** (`SW1` Prv) | Previous effect |
| **Btn 2** (`SW2` Nxt) | Next effect |
| **S1** | Brightness |
| **S2** | Speed (rev / freeze / fwd) |

Sticks: full-range Ail / Ele / Thr / Rud (sim + reactive FX 70–77).

Full list: [led-effects.md](led-effects.md)
