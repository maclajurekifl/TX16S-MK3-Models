# Switch map — Simulator

| Control | Function |
|---------|----------|
| **SB Up** | LEDs **off** |
| **SB Mid / Down** | **40 LED effects** (`ledfx`, Repeat ON) |
| **S1** | Select effect 0–39 |
| **S2** | Effect speed |

Sticks: full-range Ail / Ele / Thr / Rud (sim + reactive FX 31–37).

Full list: [led-effects.md](led-effects.md)
