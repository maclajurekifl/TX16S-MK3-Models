# Simulator

![Simulator](assets/Sim.png)

Minimal **TX16S MK3** profile for PC flight sims (USB / EdgeTX joystick). No RF — sticks at full range, plus **80 animated RGB LED effects** (SB + buttons 1/2 + S1/S2).

---

## At a glance

| Item | Detail |
|------|--------|
| Model | **Simulator** (`model7.yml`) |
| RF | **Off** |
| Sticks | Ail / Ele / Thr / Rud · **100%** |
| LEDs | **SB** off/FX · **1/2** prev/next · **S1** brightness · **S2** speed |
| Use | Select model → USB → map axes in sim |
