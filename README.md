# TX16S MK3 Models

EdgeTX model backups and SD assets for a Radiomaster **TX16S MK3**.

## Layout

```
Helicopters/
  <Model Name>/
    SD Card Files/     # Mirror of SD root — drag contents onto the TX SD (F:\)
    Documentation/     # Model homepage + guides
Drones/
  <Model Name>/
    SD Card Files/
    Documentation/
```

## Restore a model onto the transmitter

1. Plug in the TX / mount the SD (e.g. `F:\`).
2. Open that model’s **`SD Card Files`** folder.
3. Select **all items inside** (`MODELS`, `IMAGES`, `SCRIPTS`, …).
4. Copy/merge them onto the **root** of the SD card (`F:\`), not into a subfolder.
5. Eject safely, power on the radio, select the model.

See each model’s `Documentation/RESTORE.md` for slot / `labels.yml` notes.
