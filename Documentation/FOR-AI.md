# For AI agents

Before editing this repo:

1. Read [CONVENTIONS.md](CONVENTIONS.md).
2. Put aircraft content under `Helicopters/<Name>/` or `Drones/<Name>/` — never only at repo root.
3. Keep `SD Card Files/` **droppable**: paths as on the SD root; lean, model-specific assets.
4. Model docs: homepage = that model’s `Documentation/README.md`; update links from root `README.md` when adding a model.
5. Prefer updating existing topic docs over creating near-duplicates.
6. Do not invent switch maps or curves — match the radio / `model*.yml` when available.

Repo-wide rules live in `Documentation/`. Model flying/setup detail lives under each model.
