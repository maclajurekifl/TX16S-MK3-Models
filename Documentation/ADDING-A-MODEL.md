# Adding a model

1. Create `Helicopters/<Name>/` or `Drones/<Name>/`.
2. Add `SD Card Files/` with EdgeTX root paths (`MODELS/`, `IMAGES/`, …) — only what that model needs.
3. Add `Documentation/README.md` as the homepage (image + short gist + links).
4. Add at least `RESTORE.md` and a brief `SETUP.md`.
5. Link the model from the root [README](../README.md) models table.
6. Follow [Conventions](CONVENTIONS.md).

**Refresh later:** re-copy changed SD files into `SD Card Files/`, then patch docs if switches/curves/wiring changed.
